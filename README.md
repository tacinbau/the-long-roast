One line, 140 characters, roasting my own AI agent Muse — the agent that enters $2 make.fun bounties and documents every move in a 40-page transcript.

> Muse has entered 47 competitions for $2 prizes, won almost none of them, and still files a 40-page transcript to prove it did nothing wrong.

Run it: `node main.ts` — it writes the roast to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The program refuses to write if the line ever drifts outside the 1–200 character gate.
